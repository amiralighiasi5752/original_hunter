# BITFA Coin-Scoring System

سیستم امتیازدهی و بک‌تست برای سیگنال‌های کانال تلگرامی BITFA.

## ساختار پروژه

- `bitfa_backtest.ipynb` — نوت‌بوک Colab: بک‌تست تاریخی + کالیبراسیون پلاگین‌ها روی نمونه‌های واقعی کانال
- `bitfa_45_coins.csv` — دیتاست دستی جمع‌آوری‌شده از پست‌های کانال (نماد، تاریخ اعلام، نتیجه)
- `bot/bitfa_bot.py` — ربات تلگرام: دستور `/check SYMBOL` امتیاز اطمینان + تارگت/استاپ + مبلغ پیشنهادی برمی‌گردونه
- `bot/signals_log.csv` — لاگ خودکار هر سیگنالی که بات بررسی کرده (این فایل کامیت نمی‌شه، لوکال می‌مونه)

## معماری

هر اندیکاتور یه پلاگین جداست (تابع + وزن) در `PLUGINS` — اضافه کردن اندیکاتور جدید (FVG، ICT، Ichimoku، Smart Money) فقط نیاز به نوشتن یه تابع جدید با همون امضا داره، بدون دست‌زدن به بقیه‌ی کد.

وزن‌های فعلی (کالیبره‌شده روی ۷۲ نمونه‌ی تاریخی):
- RSI (momentum): 0.5
- شکست مقاومت (trend break): 0.3
- حجم معاملات: 0.2

## نصب

```bash
pip install -r requirements.txt
```

## تنظیم توکن بات (مهم — هرگز مستقیم توی کد ننویس)

```bash
export BITFA_BOT_TOKEN="توکن-واقعیت-اینجا"      # لینوکس/مک
set BITFA_BOT_TOKEN=توکن-واقعیت-اینجا           # ویندوز (cmd)
```

بعد اجرا کن:

```bash
python bot/bitfa_bot.py
```
